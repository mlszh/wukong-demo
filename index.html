03 · Understand the two branches

Same input · different jobs
FMB · creates crosses

Embedding-wise interactions

Creates scalar pair interactions by dot product, then transforms those scalars back into new embeddings with an MLP. Those embeddings can participate in the next layer's interactions.

X [n,d] → XXᵀ [n,n] → MLP [nF·d] → [nF,d]

Optimized option: X(XᵀY) [n,k] instead of XXᵀ [n,n].

LCB · preserves lower orders

Linear recombination

Compresses the embedding-count axis: each new embedding is a learned weighted sum of input embeddings. No additional explicit multiplicative feature order.

X [n,d] → WᴸX [nL,d]

For our toy: 3 rows → 1 row while dimension d=2 stays unchanged.

Stack depth and representational order

2ᴸ is the paper's maximum explicit interaction order after L layers, not a guarantee that every interaction is learned. Nonlinear MLPs also complicate a strict polynomial reading.
